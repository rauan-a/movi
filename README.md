# Наши фильмы

Сайт-список фильмов, которые вы посмотрели вместе: тёмная сетка с постерами, счётчик, список «Хотим посмотреть» и кнопка «Случайный фильм». Добавлять, переносить и удалять фильмы можно только с секретным кодом.

Стек: Next.js 14 (App Router) + Supabase (база) + TMDB (постеры и поиск) + Vercel (хостинг).

## 1. Supabase (база данных)

1. Создай проект на https://supabase.com.
2. Открой **SQL Editor**, вставь содержимое файла `supabase/schema.sql` и нажми Run.
3. Открой **Project Settings → API** и скопируй:
   - `Project URL` → это `SUPABASE_URL`
   - ключ `service_role` → это `SUPABASE_SERVICE_ROLE_KEY` (секретный, никому не показывай)

## 2. TMDB (поиск фильмов и постеры)

1. Зарегистрируйся на https://www.themoviedb.org.
2. **Settings → API** → запроси ключ (тип Developer, для личного некоммерческого проекта).
3. Скопируй **API Key** (короткий, v3) → это `TMDB_API_KEY`.

## 3. GitHub и Vercel

1. Загрузи проект в новый репозиторий на GitHub.
2. На https://vercel.com нажми **Add New → Project** и выбери репозиторий.
3. В **Environment Variables** добавь четыре переменные:

| Имя | Значение |
| --- | --- |
| `SECRET_CODE` | длинный случайный секретный код |
| `SUPABASE_URL` | из Supabase |
| `SUPABASE_SERVICE_ROLE_KEY` | из Supabase |
| `TMDB_API_KEY` | из TMDB |

4. Нажми **Deploy**. Код меняется в настройках Vercel (Settings → Environment Variables), потом нужен Redeploy.

## Локальный запуск

```
npm install
cp .env.example .env.local   # заполни значения
npm run dev
```

## Как это защищено

- Код проверяется только на сервере (`lib/auth.js`), в браузер он не попадает. Регистр букв не важен.
- Таблица закрыта через RLS, ходит в неё только сервер с ключом `service_role`.
- При неверном коде ответ приходит с задержкой, чтобы код нельзя было быстро подбирать.
- Код запоминается только пока страница открыта. После обновления страницы его нужно ввести снова.

## Чтобы данные не пропали

- Удаление «мягкое»: фильм не стирается из базы, а скрывается (`deleted_at`). Вернуть его можно в Supabase → SQL Editor:
  `update movies set deleted_at = null where id = 123;`
- Бесплатные проекты Supabase «засыпают» после недели без активности. Файл `vercel.json` раз в сутки обращается к сайту, и этого достаточно, чтобы проект не засыпал.
- Раз в пару месяцев можно сделать резервную копию: Supabase → Table Editor → movies → Export to CSV.
